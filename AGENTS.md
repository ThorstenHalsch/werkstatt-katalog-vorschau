# Public workshop catalogue preview

This repository is public. Ship only handcrafted generic package proposals.
Never add invoice exports, source mappings, customer/vehicle data, credentials,
private feedback files, application code or full application documentation.
Keep index.html self-contained, local CSS/JS, no CDN/analytics/token or API writes.
Feedback goes to the separate private feedback repository through an explicit
GitHub confirmation, never directly to the application. Preserve stable proposal
and variant keys and change review edition when the proposal meaning changes.
Do not add Actions or enable Pages without explicit publication authorization.
Test desktop/tablet layout, keyboard, answer persistence/export, safe user text,
URL limits and feedback mapping. Do not submit real test issues.
